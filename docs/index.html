微信机器人简易助手

基于 openwechat + OpenAI API + Docker

实现基本的消息（好友、群组）接收与自定义回复、公众号消息监听。 方便在微信中使用 ChatGPT 或者使用自己部署的开源大模型（如 Qwen、GLM、llama2、baichuan2……）

查看 GitHub
非官方产品有被封号风险，请使用小号作为 Bot 尝试

核心功能

开箱即用的微信机器人解决方案，支持多种 AI 模型

智能消息回复

支持好友消息、群组消息的智能接收与自定义回复，基于 AI 模型实现自然对话。

多模型支持

支持 ChatGPT 及自己部署的开源大模型（Qwen、GLM、llama2、baichuan2 等）。

Docker 容器化

一键 Docker 部署，开箱即用。支持数据持久化，重启后自动恢复登录状态。

公众号监听

支持公众号消息监听功能，不错过重要资讯更新。

自动重连

智能断线重连机制，确保服务稳定运行，手机扫码登录后自动保持连接。

开源项目

完全开源，基于 openwechat 项目。详细文档请查看 GitHub 仓库。

快速开始

三步即可搭建你的专属微信机器人

1

配置 API

【可选】注册 OpenAI 并获取其 token，或使用自己部署的开源模型

2

运行 Docker

执行 Docker 命令启动服务，首次运行复制控制台链接访问扫描登录

3

开始使用

后续自动推消息到手机登录，即可在微信中使用 AI 助手

Docker 运行命令

docker run -d \
-p 8888:8080 \
--name samge_wx_bot \
-v xxx/docker_data/samge_wx_bot/wxBotCache:/app/tmp/wxBotCache \
-v xxx/docker_data/samge_wx_bot/config.json:/app/config.json \
--restart always \
samge/samge_wx_bot:v2

常见问题

关于使用微信机器人助手的常见疑问

如何避免封号风险？
建议使用小号作为 Bot 尝试。避免频繁发送消息，注意控制频率。本项目仅供技术交流使用。
支持哪些 AI 模型？
支持 OpenAI ChatGPT 以及自己部署的开源大模型，包括 Qwen、GLM、llama2、baichuan2 等。
Docker 部署后如何登录？
首次运行时复制控制台输出的链接，在浏览器中访问并扫描二维码登录。后续会自动推消息到手机登录。
如何获取技术支持？
可以加入我们的 Discord 社区或添加微信 SamgeApp 进行技术交流。
